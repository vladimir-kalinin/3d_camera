# Приложение "Моя 3D Камера"

## Описание проекта
Это Android-приложение для создания 3D-фотографий с использованием двух камер мобильного устройства. Приложение одновременно использует широкоугольную и основную камеры для создания стереоскопических изображений, которые можно просматривать как 3D-снимки.

## Функциональность
- Одновременное использование двух физических камер смартфона
- Настройка зума для каждой камеры независимо
- Автофокус для обеих камер
- Создание стереопар для 3D-эффекта
- Сохранение настроек зума между запусками приложения

## Особенности приложения
- Использование Camera2 API для доступа к камерам устройства
- Поддержка логических камер с несколькими физическими сенсорами
- Работа с потоками через HandlerThread для обработки изображений
- Контроль зума и автофокуса для обеих камер
- Сохранение пользовательских настроек с помощью SharedPreferences

## Оптимизации производительности камер
В приложении реализованы следующие оптимизации для повышения отзывчивости камер:

1. **Оптимизация обработки зума**
   - Проверка изменения значений зума перед отправкой запросов
   - Отложенное применение зума при движении ползунка
   - Применение зума только после завершения перетаскивания
   - Отложенное сохранение настроек зума для снижения нагрузки

2. **Оптимизация автофокуса**
   - Ограничение частоты срабатывания автофокуса
   - Механизм burst-запросов для параллельной фокусировки обеих камер
   - Проверка состояния автофокуса и быстрое восстановление сессии

3. **Оптимизация настроек камер**
   - Приоритет скорости над качеством для режимов снижения шума
   - Использование режимов быстрой обработки для экспозиции и фокуса
   - Минимизация обработки изображения для ускорения отклика
   - Оптимизированные параметры стабилизации и контроля камеры

4. **Оптимизация сессий камеры**
   - Кэширование размеров предпросмотра для ускорения переконфигурации
   - Более эффективная инициализация сессий камеры
   - Улучшенная обработка ошибок и запасные варианты

5. **Общие оптимизации**
   - Уменьшение количества обращений к Camera API
   - Использование burst-запросов вместо последовательных
   - Параллельная обработка запросов для обеих камер

## Как работает приложение
1. Приложение обнаруживает доступные камеры устройства
2. Определяет логическую камеру, содержащую широкоугольный и основной сенсоры
3. Создает два предпросмотра, по одному для каждой камеры
4. При изменении зума оптимизированно обновляет параметры камер
5. Сохраняет настройки зума для следующего запуска приложения

## Требования
- Android 10 или выше
- Устройство с двумя и более камерами (желательно с широкоугольной и основной)
- Поддержка Camera2 API уровня 3 (LEVEL_3) для полной функциональности
